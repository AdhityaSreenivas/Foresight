# Live Counting Webpage (FORESIGHT Live PSIF Processing)

A real-time animated incident processing and live counting dashboard for industrial safety investigations.

## Quick Start

1. Open `index.html` directly in any modern web browser (Edge, Chrome, Safari, Firefox).
2. Alternatively, serve via Python:
   ```bash
   python -m http.server 8085
   ```
   Then open [http://localhost:8085](http://localhost:8085).

## Included Files
- `index.html` (Live processing and counting dashboard)
- `live-psif-processing-dashboard.html` (Original standalone copy)
- `incident-classification.html` (Incident classification & investigation panel)
- `tests/` (Automated DOM & interaction test scripts)
